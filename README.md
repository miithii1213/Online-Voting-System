Online Voting System

About the Project

The Online Voting System is a Java-based desktop application developed using Object-Oriented Programming concepts. It provides a simple and organized platform for voter registration, login, candidate selection, vote submission, and result management.

The system uses a graphical user interface built with Java Swing and stores voting-related information using files.

Features

- Voter registration
- Voter login
- Candidate selection
- Vote submission
- Duplicate-vote prevention
- Vote count management
- Result calculation with percentages
- Admin result viewing
- File-based data storage
- User-friendly Java Swing interface

Technologies Used

- Java
- Java Swing
- Object-Oriented Programming (OOP)
- File Handling

OOP Concepts Used

- Classes and Objects
- Encapsulation
- Constructors
- Methods
- Inheritance
- Abstraction

Project Objective

The main objective of this project is to demonstrate how Object-Oriented Programming concepts can be applied to develop a simple voting management application.

How to Run

1. Make sure Java JDK is installed.
2. Open the project folder in VS Code or another Java IDE.
3. Compile the Java files:

javac OnlineVotingSystem.java

4. Run the application:

java OnlineVotingSystem

«If your project uses "VotingUI.java" as the main GUI file, run that class instead.»
